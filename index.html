Game Ports and Remakes

The Last Mission

Classic 1987 arcade remake — guide a flying robot and caterpillar platform through underground labyrinth levels. Originally by Opera Soft, remade in C/SDL with hand-colorized 256-color graphics.

View Details

Wetspot II

Re-implementation of the 1997 QuickBasic classic. Push blocks to crush enemies as a crab hero in this Pengo-like puzzle-action game. Full SDL port with preserved graphics, SFX and AdLib music.

View Details

XRACE

JS port of DOS Mode 13h shooter — 320×200 indexed framebuffer with 256-color palette. Dodge comets, blast foes, manage Life/Power/Shield.

View Details

Lala Prologue

TypeScript port of the Mojon Twins' DOS platformer — 320×200 VGA, flip-screen and smooth-scroll modes, FM music.

View Details

Involvement in other projects

Adlib Tracker II

A feature-rich FM music tracker for the OPL3 chip found in Sound Blaster cards. Ported the tracker to FreePascal/SDL, enabling it to run on modern systems.

Visit Site

GCW Zero

An open-source gaming handheld built by gamers for gamers. Contributed to the OpenDingux firmware and developed software for the device.

Archive

The Last Mission Remake

A modern remake of the classic 1987 side-view arcade game by Opera Soft. Rewrote the game engine in C with SDL for cross-platform support.

OpenDingux Development

Development and documentation for OpenDingux firmware on Ingenic JZ47xx devices including Dingoo A320, Ritmix RZX-50, and GCW Zero.
