XRACE

JS port of the DOS Mode 13h game — 320×200 indexed framebuffer on <canvas>. Ported from XRACE.ASM.

Controls
Move: Arrow keys — Fire: Space — Recharge: Enter — Quit: Q
Click canvas to focus if keys don’t respond. Uses DOS scancode emulation.
Source code on GitHub
Created with Astro, Tailwind/Flowbite and Svelte.
